# План автономной работы над PS2-переводом (2026-11-09)

Цель: довести PS2-перевод до беты без участия пользователя в рутине. Пользователь нужен только для: публикации релизов (по команде), решений по спорному тексту и проверок, где нужны его руки (консоль, свой экземпляр PCSX2).

## Правила
- Эмулятор — только пока пользователь не за компьютером: `press` забирает фокус окна и клавиатуру. Всё, что можно сделать файлами и скриптами, делаю без эмулятора.
- Ввод в игру: F-клавиши, раскладка не важна (`docs/pcsx2-paths.md`). Проверка «дошла ли кнопка» — по обрезке кадра, не по просмотру снимков (`pcsx2_lines.py`).
- Каждый шаг: скрипт или проверка → коммит с сообщением (что и зачем). Релиз и пуш в GitHub — только по команде.
- После любой правки текста или сборки: `ps2_all.py --write build/ps2/relN.iso` и `ps2_audit.py build/ps2/relN.iso` (должно быть 0 нарушений, кроме известной сцены R08/37).
- Решение, которое меняет перевод (термин, ты/вы), сверять с `text/STYLE.md` и `text/chars/*.md`, спорное — в список вопросов, не молча.

## Дорожки (по порядку выгоды)
1. **ГОТОВО (2026-11-09): R08, блок 37 (сцена C09_07).** Остаётся японской: блок не влезает в контейнер. Идеи: общие записи реплик (dedupe) для этой сцены, более мелкий кегль, вынос повторяющихся реплик. Критерий: `ps2_all.py` без ПРОБЛЕМЫ. Сделано через `text/ps2/ru_override.tsv` (правки текста только для PS2, DS не трогаем): блок не влезал на 80 байт, убраны редкие глифы (ъ, ё, «-», «А», «Я») перефразировкой 4 реплик; все 600 блоков собираются, `ps2_audit.py` — 0 нарушений, образ `build/ps2/rel3.iso`. Тем же способом решаются другие блоки, которым не хватает байтов.
2. **ГОТОВО (2026-11-09): японские строки без английского.** 435 из 486 строк переведены с японского (подсказки Катарины «ヒントその…», ответы, сказание о 11 детях в R17, реплики R16/R18/R19, возгласы) в `text/ps2/ru_ps2only.tsv` (файл, блок, строка, текст; `ps2_all.py` и `ps2_audit.py` подхватывают сами). Строки рисуются скриптом `ps2_jp_lines.py` (`dumps/ps2/jp/*.png`). Остались японскими (51): числа-ответы, латинские титры и заставки (MIX, JAZZ, MEMORY, SUPPORT/DEVELOPMENT/PUBLISH, SEE YOU AGAIN), многоточия, таблица каны `OP.BIN` блок 24 и нечитаемая строка 29 в блоке 29 `OP.BIN`. Образ `build/ps2/rel3.iso` (7050 реплик, 0 нарушений аудита). Сомнительные места для пользователя: R02/58 «Трекуартиста — одна четверть» (на экране цифра читалась как 1, по смыслу вероятнее «три четверти»), R10/41 «Дульциана» (регистр органа), R17 «Элекинг» (в R08 «Элекинг» — монстр/остров Элеки), пол говорящей в подсказках Катарины (оставлено без рода).
3. **Окна и кегль.** Сцены, где кегль упал ниже 24 (~50 блоков): попробовать вернуть крупнее за счёт переразбиения реплик (нельзя: игра не переносит слов, но можно подтянуть общие записи) или сократить тексты. Метрика: число блоков с кеглем < 24 в выводе `ps2_all.py`.
4. **Выборочная проверка в игре.** По 1–2 реплики на главу через состояния (`save`/`load` слоты) в окно, когда пользователь не за компьютером. Цель — не найти ошибки перевода, а убедиться, что окна не пустые и сцена не падает. Хватает 19 глав × 2 кадра.
5. **Интерфейс `YOSHI.BIN` / `NAKA.BIN` (картинки меню).** Кодек не найден (`docs/ps2-plan.md`, раздел разведки). Ходы: (а) дизассемблер R5900 для `SLPS_250.34` (самописный или Ghidra с плагином emotionengine в headless) и чтение распаковщика; (б) парные данные: сжатая запись и распакованная картинка из `GS.bin` состояния с тем же экраном. Критерий успеха: распаковать японскую картинку и упаковать обратно так, чтобы игра её приняла. Без этого интерфейс остаётся японским; сроки неизвестны, брать после дорожек 1–4.
6. **Остальное:** `MOVIE.BIN` (титры видео), файлы `R00`, `GDB`, `SYSTEM`, `WAT`, `TORU*` — сначала разведка (что там внутри), потом решение.
