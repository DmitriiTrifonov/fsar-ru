# Инструкция субагенту: перевод страниц LostList (список находок, головоломки)

Проект: русификатор Flower, Sun and Rain (DS). Страницы LostList — карточки с загадками «потерянных вещей» (`lostSTR_r00 … r18`, пергаментный фон, тёмный текст). Игрок решает загадки и вводит числовой код, поэтому перевод обязан сохранять решаемость: цифры, формулы, буквы-подсказки, порядок слов в таблицах — как в оригинале.

## Что делать на каждой странице
1. `cd ~/Developer/games/fsar-ru`; `tools/venv/bin/python -I scripts/gfx_lost.py lostSTR_rNN --skel` — создаёт `text/gfx/LostList/lostSTR_rNN.tsv` (по строке на блок: `id<TAB>EN<TAB>RU`) и печатает блоки: `h` — заголовок (с подчёркиванием, 1 строка), `b` — текст (lines — число строк, room — свободные пиксели под блоком, текст может занять свободное место ниже, до следующего блока).
2. Открой Read-ом `dumps/gfx/skel/LostList_lostSTR_rNN.png` (вся страница ×3 с номерами блоков) и при необходимости `dumps/gfx/skel/LostList_lostSTR_rNN_b<id>.png` (блок ×4). Прочти английский текст точно.
3. Заполни EN (как прочитал, одной строкой) и RU (перевод одной строкой). Переносы по строкам программа расставляет сама; принудительный перенос — ` // ` (например, между условием и строками данных: `Какое число? // 0 = k  1 = c`).
4. Проверка: `tools/venv/bin/python -I scripts/gfx_lost.py lostSTR_rNN --check` → `ok`. `BAD (i, "N/M")` — перевод занял N строк при M доступных → сократи; `missing [...]` — нет такого символа в шрифте (есть кириллица, ЛАТИНИЦА, цифры и . , : ; ! ? - — « » ( ) " ' / % + = … [ ] ° × → _; нет «№», «ё» есть). Правь, пока не будет `ok`. Файлы страниц пересобирает координатор.

## Правила
- Решаемость: если ответ получается из букв или цифр названия (например «Mr. MONDO is 131514415, EDO is 5415, so what is EL?», «0 = k 1 = c…», «Reduce the Peppermint Green to 10ml…»), ОСТАВЬ такие места латиницей/как есть — игра проверяет код, а он зависит от английских букв. Перевод вопроса вокруг — русский. Если задача решается только по английскому слову (анаграмма, шифр), кратко оставь английское слово в кавычках. Если не уверен — не ломай: сохрани оригинал и напиши о спорном в отчёте.
- Названия и термины — как в уже переведённых репликах: `text/STYLE.md`, `text/ru.csv` (ищи по англ. слову через `grep -n "слово" text/dialogue.csv | head`). Известно: Chiba-Chiba → «Чиба-Чиба»; Lospass Mob → «Лоспасс Моб»; Power Beach → «Пляж Энергии»; отель «Цветок, Солнце и Дождь»; Edo → Эдо (управляющий); Mondo → Мондо; Mr. Pirate → мистер Пират; Sister Phantom → сестра Фантом; Mr. Charbonie → мистер Шарбони; Miss Akai → мисс Акаи; Mati → Мати; Sue → Сью; Mr. Crasher → мистер Крашер; Miss Hanayama → мисс Ханаяма.
- Заголовки (`h`): короткие, нумерация «1.», «2.» сохраняется; ширина ограничена (один заголовок ~ 28 символов).
- Русский шрифт шире английского на ~15 %: пиши компактно, но без потери данных (все числа, единицы, условия).
- Блоки-картинки (схемы, головоломки-кресты, диск пластинки, перевёрнутый текст, рамки с цифрами): RU пустой, в EN напиши `SKIP: причина`. Если картинка содержит английский текст, который нужен игроку, опиши в отчёте.
- Страница-счётчик «1/3» и подобное не трогаем (не является блоком).

## Отчёт
Коротко: какие страницы `ok`, что SKIP, спорные места (особенно головоломки, где перевод мог бы нарушить решение: перечисли их явно), список «английский → русский» для новых терминов. Только TSV, не коммить, ром не собирай.
