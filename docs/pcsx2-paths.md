# Карта путей по меню PS2-игры (PCSX2, 2026-11-09)
Кнопки: подтверждение CIRCLE, отмена CROSS, пропуск START. Нажимать с паузой 2,5 с после стрелок.

```
запуск rel.iso → заставка (START) → «Hello!! MEMORY CARD» (CROSS) → ГЛАВНОЕ МЕНЮ
ГЛАВНОЕ МЕНЮ (4 полосы справа): 0 Play Start · 1 Request · 2 Movie · 3 Option
  Play Start → New Game / Continue R-06
  Request    → список R-00…R-03 справа + NEXT и Back слева (по 4 на странице)
  Movie      → видео (CROSS — выход)
  Option     → Save/Load · Sound · Vibration (CROSS — назад, курсор остаётся на Option)
```

## Курсор главного меню по яркости (работает)
Выбранная полоса пульсирует: яркость то падает (~96 при базе 117–127), то растёт (+10…+60). `pcsx2_nav.bar_dev` сравнивает среднюю яркость каждой полосы (точки в координатах 640×480: y = 92/145/195/247, x от 480/520/570/600) с базой `[117,117,119,127]`; `cursor()` берёт до 3 кадров и выбирает полосу с наибольшим |отклонением|. `goto_item(i)` — Down/Up по замеру, `open_request()` — курсор на Request и Circle. Проверено: из любого пункта доходит до списка R-00…R-03.

## Список Request (не доделано)
Те же 4 полосы (R-00…R-03) на тех же позициях, `cursor()` часто даёт верный индекс (R-00 → отклонение +66 на светлой фазе), но надёжность ниже: подряд Up, Up, Down давали 3, 1, 1. Стрелки Down с R-03 и Left не перенесли на NEXT/Circle не сменил страницу (экран не менялся) — возможно, глава заблокирована сохранением или NEXT надо выбирать иначе. Следующие шаги: замерять фазу пульсации серией из 3–4 кадров, проверить, что Circle на R-00 запускает главу, найти кнопку перехода на NEXT (Right?).
Резерв: загрузить состояние (`load <слот>`) с уже выбранной главой.

## Ввод и раскладка (2026-11-09)
Буквы (X, Z, S, A) работают только при латинской раскладке macOS; F-клавиши (F13–F20), Return и стрелки — при любой. Драйвер шлёт F-клавиши и стрелки-Home/End; `pcsx2_ctl.layout()` читает текущую раскладку (`defaults read com.apple.HIToolbox AppleCurrentKeyboardLayoutInputSourceID`). Проверка «дошла ли кнопка»: сравнивать обрезку окна диалога (y 380–480 в 640×480) до и после нажатия, а не смотреть кадры.
В профиле у каждой кнопки две привязки: F-клавиша и обычная (X=Cross, Z=Circle, Return=Start, стрелки) для ручной игры.
