# PS2 (SLPS-25034): формат текста реплик

Статус на 2026-10-22: формат разобран, пролог (`OP.BIN`, блок 26) собран по-русски и проверен в PCSX2 2.8.2 (программный рендер). Образы в `roms/` (Japan и English v1.0, оба 3 759 833 088 байт, раскладка файлов одинакова), в git не входят.

## Образы и файлы
- Английский патч меняет только `DATA/EVENT/OP.BIN`, `R01…R19.BIN` (кроме R00, GDB), `DATA/YOSHI/YOSHI.BIN`, `DATA/NAKA/NAKA.BIN`. `SLPS_250.34` не тронут: текст и шрифт в данных.
- Игра находит файлы по именам (в исполняемом файле номеров секторов `OP.BIN` нет).

## Контейнер `DATA/EVENT/*.BIN` (`LF?\0`)
- Таблица в начале: `w[3]` = размер таблицы в секторах (2048), с байта 12 пары `(сектор, размер)`. Блоки идут впритык, каждый начинается с границы сектора; контейнер занят полностью (хвоста нет), поэтому размер файла менять нельзя.
- Сцены с репликами: `OP.BIN` блоки 26–42, `R01.BIN` блоки 18–51. Первый `u16` блока = число строк.

## Блок сцены
```
u16 nlines, u16 ntex (число атласов), u16 nglyph, u16 0x200
u32 off_lines(=0x18), off_lines_end, off_glyphs, off_glyphs_end
u32[nlines] смещения строк
u32 off_gs (начало GS-пакетов), u32 (ntex=2: смещение второго пакета; ntex=1: id палитры <<16)
глифы по 16 байт: u32 (id палитры <<16, один на сцену), u16 w, u16 h(=32), f32 u, f32 v   (x=u*256, y=v*512)
12 нулевых байт
строки: флаги 8 байт (байт 2 = число рядов, 4..7 = стиль), u32 0x18, 12 нулей,
        таблица смещений рядов (u32 на ряд, от начала строки),
        ряды: u32 n, n × u16 номеров глифов (0x8400 = пробел), выравнивание до 4
выравнивание до 16, дальше GS-пакеты
```
- GS-пакет: DMA-тег (QWC 0x1010), A+D (BITBLTBUF/TRXPOS/TRXREG/TRXDIR), IMAGE-метка и 64 КБ атласа 256×512 PSMT4 **линейно** (без свиззла, 2 пикселя в байте, младший полубайт первым), затем загрузка палитры 8×2.
- Игра при загрузке переписывает смещения в заголовке на абсолютные адреса и правит теги DMA (QWC 0x1010 → 0x1006). Геометрия атласа жёстко 256×512, ужимать нельзя.
- Индексы в глифах: 0 = фон (прозрачно), 1 = основной цвет чернил, 2…15 = полутона краёв в неизвестном порядке.

## Что нельзя трогать в атласе
Верх атласа (x < 128, y < ~100) и всё, что не занято ячейками глифов, может быть картинками (баннер «on air»). Свободная область, проверенная в игре: y ≥ 288. Если стереть верх атласа, текст перестаёт рисоваться.

## Скрипты
- `scripts/ps2_scene.py <BIN> <блок> [префикс]` — разбор, PNG атласа и строк.
- `scripts/ps2_build.py` — `build_scene` (новый блок из русских строк) и `repack_container` (блоки встык, размер файла прежний).
- `scripts/ps2_test1.py`, `ps2_test2.py` — опыты: подмена одной реплики на месте, вся сцена пролога (`OUT=…` образ в `build/ps2/`). Запуск `tools/venv/bin/python -I`.
- Шрифт: Nunito (OFL, `tools/fonts/nunito/`), кегль 27, Bold, базовая линия в ячейке 32 px на строке 24.

## Палитра текста (проба 2026-10-22)
Индекс 0 прозрачен, индексы 1…15 идут по убыванию непрозрачности (1 = чернила, 15 = едва видно) ровной лесенкой. Проба снята 2026-10-23 (снимок F8 с `probe.iso`): яркость квадратов 1…15 растёт почти линейно (47, 50, 56, 61, 66, 71, 75, 80, 85, 91, 96, 102, 108, 115, 122 на фоне ≈135; индекс 15 почти сливается с фоном), то есть линейная модель верна, у тёмного края шаг чуть меньше. Используется модель `alpha(i) = (16 - i) / 15` (`coverage_to_index` в `ps2_build.py`). Для калибровки есть `scripts/ps2_probe_palette.py` (образ `build/ps2/probe.iso`: первая реплика пролога = 16 квадратов с индексами 0…15, скриншот по F8).

## Проверка test4.iso (2026-10-23)
Сглаживание по линейной модели работает: края ровные, баннер «on air» цел (его смазывание в начале сцены есть и у непереведённых сцен, это не наша ошибка), 3 ряда помещаются по высоте. Проблема: ряд шире ≈ 390 px (в единицах ширин глифов) наезжает на звезду F.S.R. справа («что», «найти» налезали на неё). Предел ряда теперь `MAXW_SCREEN = 365` в `ps2_test2.py`; проверочный образ `build/ps2/test5.iso`. Для общего конвейера тот же предел.

## Не проверено
Остальные сцены и главы, заставка «冒險の始まりだ», перепаковка при росте блоков больше одного сектора, самая широкая реплика (01012) в игре.
