# Названия музыкальных тем: `2D/SubTitle.pobj` (отложено, 2026-10-23)

Плашки с названиями треков (звуковой тест / проигрыватель). 19 ячеек, у каждой своя ширина. Переведены только 0 и 17; остальные оставлены по решению пользователя (общепринятые названия произведений). Ниже заготовка на случай, если решим переводить.

## Куда класть
`scripts/stage4_labels.py`, словарь `BOXED`, ключ `"decoded/2D/SubTitle.pobj"` (сейчас там ячейки 0 и 17). Формат записи: `номер: (["строка", ...], dict(bold=0, space=0, margin=3, gain=1.2))`. Результат: `patched_raw/2D/SubTitle.pobj.z`, подхватывается `build_rom.py`. Запуск: `tools/venv/bin/python -I scripts/stage4_labels.py [--preview]`. Предпросмотр ячеек: `pobj_edit.Pobj('decoded/2D/SubTitle.pobj').render(i, scale=1)`. После правки перерисовать и проверить в игре; раскладку рома не менять (файл не должен вырасти за границу блока, см. AGENTS.md).
