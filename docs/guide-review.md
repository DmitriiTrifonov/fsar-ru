## Как смотреть страницы Guide через MCP (отработано 2026-10-18)
1. Опорное состояние: `states/guide-grid.ml3` (сетка страниц; копия слота 3 на gfx9, для нового рома скопировать в `build/<rom>.ml3`).
2. **Каждую страницу начинать с `emu_open` заново**: после `emu_load_state` в уже работавшей сессии касания перестают доходить до игры, работает только первое касание после свежего `emu_open`.
3. `emu_open(rom)` → `emu_load_state(states/guide-grid.ml3)` → `emu_run 30` → `emu_touch` по плитке (нижний экран, координаты в пикселях; ряд 36–43: y=152, x = 16 + 32·(номер − 36); ряд 28–35: y=128; ряд 20–27: y=104; ряды 4–11 и 12–18: y=32 и 56).
4. Прокрутка: касание розовой стрелки ▼ (235,137) на 60 кадров, сдвиг примерно на экран; кнопки D-pad Down/Right ведут себя непредсказуемо (листают страницы).
5. `shot` в скрипте пишет PPM под именем .png; склейка нижних экранов: `tools/venv/bin/python -I scripts/guide_shots.py --stitch <страница>` (префикс файлов `q<NN>_<k>.png`).

## LostList: номер карточки в памяти (2026-10-18)
Номер списка = слово по адресу ARM9 `0x02078638` (в файле состояния смещение `0x2078638 - 0x01FFFFDC`), в первой карточке равно 1. Нашёл по литералу формата `%slostSTR_r%02d%s` (функция в `0x020A49C0`, `[G+0xC]` где `G=0x0207862C`). Подмена: записать нужное число в копию состояния, снятого ДО открытия карточки (карточка уже на экране не перерисуется). `build/fsar-gfx9.ml6|7|8` = слот 5 с номером 2 / 5 / 10.
