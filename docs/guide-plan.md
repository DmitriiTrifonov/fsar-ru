# План: графика Guide (49 страниц) и LostList (21 страница)

Страницы — длинные ленты `.pbg` (256 × 384…1392). Guide: белый 1-битный текст (индекс 2) на прозрачном (0), шрифт моноширинный квадратный, x-height 6, шаг строк 11, ~5 px/символ. LostList: тёмный сглаженный текст на пергаменте (банк 0, 16 цветов), заголовки крупнее с подчёркиванием.
Русский текст длиннее английского на 20–30 %, а высота страницы фиксирована (карта тайлов «один тайл на ячейку»), поэтому перевод пишется под рамку блока: ширина × число строк.
