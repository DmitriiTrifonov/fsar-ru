## 2. TAS + сейвстейты вместе (главное на день)
Идея: два разных механизма, каждый для своего случая.
- **Только графика изменилась** (спрайты `.pobj`, страницы `.pbg`): берём любой сейвстейт и подменяем тайлы `scripts/patch_state_gfx.py` — секунды, без прохождения. Работает для `.pobj`; для длинных лент `.pbg` (Guide/LostList) в сейвстейте лежит только видимая часть, подмена даёт кашу → для них нужен путь 2б.
- **Менялся текст/скрипты сцен** (диалоги): сейвстейт хранит уже загруженный скрипт сцены, подменить нельзя → нужен прогон макроса (TAS), который доходит до сцены на свежем ромe.

Шаги:
1. Формат макроса `macros/<имя>.txt`: `wait N`, `keys HEX N`, `touch x y`, `checkpoint <имя>` (на чекпоинте драйвер сохраняет `dumps/emu/cp_<имя>.ml1`), `wait_pixel x y RRGGBB [timeout]` (ждать появления окна диалога, чтобы макрос не ломался от смены длины реплик). Проигрыватель: расширить `scripts/emu_run.py`.
2. Запись: логирование команд, которые я подаю драйверу (я уже вожу его руками). Детерминизм подтверждён: два прогона дают побайтово одинаковые сейвстейты.
3. Маршрут 1: меню → New Game → первая реплика (известен, ~3600 кадров, `Start, Start, A, ждать, A…`) → меню Кэтрин (касание чемоданчика). Макрос `intro.txt`, чекпоинты `first_dialogue`, `menu`.
4. Маршрут 2: до JACK IN (нужно найти человека у грузовика: спросить пользователя, с какой стороны и какой кнопкой; либо пользователь делает сейвстейт ml в GUI перед этим местом, а я дописываю остальное).
5. Использовать пользовательские сейвстейты из GUI (`build/<rom>.mlN`) как ускоренные точки входа: графику в них патчим `patch_state_gfx.py`; текст проверяем макросом.
6. MCP: инструмент `emu_macro(имя)` (замена этапа 3 в `docs/emu-mcp-status.md`): проигрывает макрос до чекпоинта и возвращает скриншот; `emu_checkpoint_list`. Нужен перезапуск Claude Code для активации сервера `fsar-emu` (этап 2.5).
7. Выбор главы: в строках EdoComment есть «Select a request number to play», «Select your desired request number», «Play from the start of the selected request number» (request = глава R-xx; спрайт «Заказ» в меню сохранений). Условие открытия неизвестно (внешних источников нет, GameFAQs отдаёт 403). Проверить в GUI: есть ли кнопка «Заказ» у сохранения с пройденными главами; если да — макрос «загрузить сохранение → Заказ → номер» вместо прохождения всей игры.

## 4. Релиз (по команде пользователя)
`python3 scripts/make_release.py` собирает `build/fsar-ru.nds`, делает `release/fsar-ru.xdelta` (xdelta3), проверяет применением, пишет SHA-1 в `release/CHECKSUMS.txt`. Затем README, скриншоты, обновить журнал в Obsidian. Ром и патч в git не кладём.
