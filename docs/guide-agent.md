# Инструкция субагенту: перевод страниц Guide (картинки)

Проект: русификатор Flower, Sun and Rain (DS). Страница путеводителя Guide — картинка с белым английским текстом. Ты читаешь текст по картинке и пишешь русский перевод; ничего другого не трогаешь.

## Что делать на каждой странице `m_guideNN`
1. `cd ~/Developer/games/fsar-ru`; `tools/venv/bin/python -I scripts/gfx_extract.py Guide m_guideNN --skel` — создаёт `text/gfx/Guide/m_guideNN.tsv` (по строке на блок: `id<TAB>EN<TAB>RU`) и печатает для каждого блока число строк, ширину и бюджет символов.
2. Открой Read-ом увеличенные снимки блоков `dumps/gfx/skel/Guide_m_guideNN_b<id>.png` (и общий вид `dumps/gfx/skel/Guide_m_guideNN.png`), прочти английский текст блока точно.
3. Заполни в TSV колонки EN (английский, как прочитал, одной строкой) и RU (перевод одной строкой, без табуляций и переводов строки; переносы по строкам программа расставит сама).
4. Проверка: `tools/venv/bin/python -I scripts/gfx_render.py Guide m_guideNN --check` — должно быть `ok`. Если `BAD`: `(id, "N/M")` значит перевод занял N строк при M доступных — сократи перевод (перефразируй короче, не теряя смысла); `missing [...]` — символа нет в шрифте (разрешены кириллица, цифры, . , : ; ! ? - — « » ( ) " ' / % + = … ■ & *; латиницы нет — транслитерируй или переведи; «№» заменяй на «номер»).
Правь TSV, пока все страницы не дадут `ok`. Файл `patched_raw` пересобирает координатор — ты его не создаёшь (`--check` ничего не пишет).

## Правила перевода
- Это путеводитель по острову Лоспасс (Lospass → «Лоспасс»), тон — туристический, слегка рекламный; слова автора в кавычках и реплики оставляй живыми. Любительский художественный перевод, допустимо перефразировать и сокращать мелкие детали ради размера, смысл и шутки сохраняй.
- Русский текст получается на 20–30 % длиннее английского, а место ограничено рамкой блока (ширина × число строк). Пиши компактно: короткие слова, без лишних оборотов.
- Имена, места, термины — по `text/STYLE.md` и по уже переведённым репликам: ищи в `text/ru.csv` (grep по английскому слову в `text/dialogue.csv`, например `grep -n "Power Beach" text/dialogue.csv | head`) и бери тот же вариант. Известные решения: Power Beach → «Пляж Энергии»; отель Flower, Sun and Rain → «Цветок, Солнце и Дождь»; «билет владельца»; Edo → «Эдо» (управляющий); Catherine → «Кэтрин».
- Заголовки (1 строка): короткие, без точки в конце, если в оригинале её нет. Пункты списка (блоки, начинающиеся с квадратного маркера) — маркер остаётся на месте, пиши только текст.
- Кавычки «ёлочки», тире «—», многоточие «…»; числа и единицы (мл, ° и т. п.) как в оригинале.
- Если блок — не текст (рисунок, таблица цифр, подпись, которую нельзя перевести) — оставь RU пустым и напиши причину в EN после слова SKIP: (например `SKIP: футбольная схема`).

## Отчёт
В конце коротко: какие страницы готовы (`ok`), что оставил пустым и почему, сложные места/спорные термины (список «английский → русский»). Файл TSV — единственный артефакт; не коммить, не запускай сборку рома.

## Построчные страницы (оглавление, списки с выносными линиями): m_guide02, 03, 22 (режим lines)
Здесь каждая строка переводится отдельно, 1:1, а иконка, выносная линия и номер страницы/буква справа остаются на месте.
1. `tools/venv/bin/python -I scripts/gfx_lines.py Guide m_guideNN --skel` — создаёт `text/gfx/Guide/m_guideNN.lines.tsv` (по строке `id<TAB>EN<TAB>RU`) и печатает геометрию (tx0 — начало текста, leader — выносная линия, num — номер справа).
2. Страница видна в `dumps/gfx/guide_ru/` только после рендера; для чтения оригинала используй `dumps/gfx/Guide_ue/m_guideNN.png` (вырезай нужную область через PIL: `tools/venv/bin/python -I -c "from PIL import Image; ..."` и увеличивай в 3 раза, цвет 0 — красный фон) либо общий снимок `dumps/gfx/skel/Guide_m_guideNN.png` (после `gfx_extract.py --skel` на этой странице; блоки для этой страницы не нужны, TSV блочного режима не заполняй и удали `text/gfx/Guide/m_guideNN.tsv`, если он появился).
3. Строки идут сверху вниз; строки `id` соответствуют строкам текста по порядку. Пустой EN/RU у строки = не трогаем.
4. Проверка: `tools/venv/bin/python -I scripts/gfx_lines.py Guide m_guideNN --check` → `ok`. `BAD (i, "W>L")` — строка шире допустимой (W — правый край текста в px, L — предел до выносной линии): сократи.
Ограничение строки — её же ширина минус место под линию и номер (около 8–10 px минимум), поэтому формулируй коротко, как в оригинале. Заголовки строк-секций («Enjoy a Special Day in a Tropical Chapel») можно сильно сокращать. Один перевод — одна строка (без переноса).

## Списки с выносными линиями внутри блочного режима (m_guide23, 31 и подобные)
Если блок состоит из нескольких строк, и у КАЖДОЙ строки справа есть выносная линия (сплошная или пунктирная) и номер/буква/количество (например «Dry Gin ····· 30ml» или «Cinema - Power Theatre ——— H»), пиши RU через « | » по одной части на строку блока: `Сухой джин | Виски | Перно`. Число частей = число строк блока, иначе `--check` покажет BAD. Каждая часть должна влезть слева от выносной линии (проверка покажет `W>L`). Одиночный блок из одной строки с линией переводи обычным текстом.
Блоки-рамки (цветная рамка вокруг текста или таблицы, блоки с картинками, столбики имён футболистов) — SKIP.
